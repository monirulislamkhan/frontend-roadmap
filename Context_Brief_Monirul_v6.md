## ⭐ LEARNING PROGRESS

### Session 1 — 23 July 2026 (Phase 1, Month 1, Week 1)

Office ke real code se shuru:
```js
const mappedList = objList.filter((item) => item && item.id).map(item => item);
```

**✅ DONE topics:**
1. **`&&` (AND) — poora rule clear.** `&&` pehli falsy value return karta hai; koi falsy na mile toh aakhri value. Short-circuit: pehli falsy pe ruk jaata hai (isiliye `null && item.id` crash nahi karta). `&&` sirf true/false nahi, actual value deta hai.
2. **Truthy/falsy catch:** khaali object `{}` bhi truthy hota hai. Isiliye `item &&` akela kaafi nahi, `item.id` (undefined) hi `{}` ko bahar nikaalta hai.
3. **`.map(item => item)` bekaar hai** — Monirul ne khud sahi bola. `.filter(...)` akela kaafi tha.

**Touched par ✅ NAHI (practice task pending):**
4. **Reference vs copy:** naya array banta hai par andar ke objects same. `mappedList !== objList` par `mappedList[0] === objList[0]`. → Console mein khud badal ke dekhna PENDING.

**Agla topic (Month 1, Week 1):** `??` (nullish coalescing) — `||` jaisa par sirf `null/undefined` ke liye. `0 || "x"` vs `0 ?? "x"` ka farak.
